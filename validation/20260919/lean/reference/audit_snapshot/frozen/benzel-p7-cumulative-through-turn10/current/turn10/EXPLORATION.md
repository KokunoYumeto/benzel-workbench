# Development history and corrections

This file records unsuccessful configurations and implementation corrections so they are not promoted to mathematical statements.

1. The original q=3k+2 scaffold deleted the first and once-rotated extra corner stones. After the translated first-residue repair, the second channel required a right-stone vacancy at an occupied retained stone. The inverse base-index calculation identified the required tile as the twice-rotated corner stone. The accepted constructor deletes the first and twice-rotated stones. The previous finite failure is not an impossibility result for the benzel.
2. The completed large-parameter bridge transports the beta vacancy upward by six cells using eight released bones. Its finite discovery was accepted only after literal cell expansion, parameter-preserving symbolic identity, and exact original-source certificates.
3. At k=2,3 the parent k-4 vertical sequence is outside its domain. Separate fixed terminal patches and direct bridges were found; their exact tables have independent unbounded-m polynomial identities and fixed-k source certificates. A failed intermediate beta transport is preserved only as development data.
4. A shallow-copy bug in an early small-table generator mutated parent row arrays while specializing k=2. It was corrected to deep-copy before substitution. All four accepted small tables, owner maps, exact affine certificates, symbolic identities and finite replays were rebuilt after that correction. No pre-correction table is used by the constructor.
5. Exploratory positive-collar searches for the already published residue-two family returned no solution in their restricted supports. No negative theorem follows from those optimizer outcomes. The accepted full-P7 assembly instead retains the previously source-matched published compression theorem and its exact parameter/tile-set maps.
6. Two large combined replay attempts reached the execution time limit without final receipts. Their partial logs are not used as PASS evidence. The final accepted runs use the explicitly recorded d=2..12 all-h window, additional large-k samples, every exceptional branch, and the full unbounded polynomial/affine certificate replays.

Optional development scripts and their intermediate JSON files are preserved under `development/`; some were written for execution from the original working directory before archival. They are not called by the accepted standard-library verifier. `build_small.py` and `build_edits.py` describe table construction, but verification uses the final owner-bearing tables directly, not a regeneration that would discard their owner maps.
